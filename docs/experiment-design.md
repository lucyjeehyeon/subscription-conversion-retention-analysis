# 온보딩 실험 설계

이 문서는 원 프로젝트의 제안을 포트폴리오 정리 과정에서 명확히 한 설계안입니다. 실험은 실시하지 않았습니다.

## 검증할 가설

가입 직후 콘텐츠 경험이 없는 신규 유저에게 beginner 콘텐츠 추천과 원클릭 시작 CTA를 제공하면, 기존 화면 대비 7일 이내 콘텐츠 경험 비율이 높아지는지 확인합니다.

| 항목 | 설계 |
|---|---|
| 배정 시점 | 가입 완료 후, 콘텐츠 조회·시작이 발생하기 전 |
| 대상 | 배정 시점에 가입과 콘텐츠 경험 여부를 확인할 수 있는 신규 유저 |
| 실험 단위 | 유저. 최초 배정을 유지하고 A/B 50:50 무작위 배정 |
| 대조군 | 기존 메인·온보딩 화면 |
| 실험군 | beginner 콘텐츠 추천 + 원클릭 시작 CTA |
| 1차 지표 | 배정 후 7일 이내 콘텐츠 조회 또는 시작한 유저 / 배정 유저 |
| 보조 지표 | 콘텐츠 조회율, 시작률, 레슨 완료율 |
| 가드레일 | 30일 내 첫 결제율, 사전 정의한 이탈 지표. 이탈 이벤트·허용 악화폭은 실험 전 확정 |
| 분석 원칙 | 최초 배정 집단 기준 분석, 동일한 관찰기간 확보, 중간 결과를 보고 임의 종료하지 않음 |
| 비교 방법 | 사전 계획한 두 집단 비율 비교와 차이의 신뢰구간. 다중 보조지표는 탐색 결과로 구분 |

‘7일간 아무 행동을 하지 않은 사람’을 7일이 지난 뒤 선택하면서, 같은 기간의 행동을 실험 결과로 평가하면 안 됩니다. 대상은 **배정 시점에 알 수 있는 정보**로 결정합니다.

## 기준율과 표본 수

원본의 37.01%는 과거 ‘레슨 완료 0회’ 집단 33,556명 중 콘텐츠 경험자 12,419명의 비율입니다. 이는 위 실험의 가입 직후 배정 모집단과 다르므로 그대로 실험 기준율로 사용하지 않습니다.

실험 전 같은 자격 조건·관찰기간의 기준율을 계산하거나 파일럿으로 추정한 다음, 사업적으로 의미 있는 최소 차이(MDE), 유의수준, 검정력을 정하고 표본 수와 기간을 산정합니다. 원본의 1,491명/그룹·19일을 검증된 소요 표본·기간으로 재사용하지 않았습니다.

## 매출 시나리오와 실험 효과를 구분

과거 세그먼트 간 결제율 차이를 활용한 시뮬레이션은 다음 가정입니다.

`대상 세그먼트 인원 × 다음 세그먼트로 이동하는 비중 × 두 그룹의 결제율 차이 × 평균 첫 결제금액`

무행동형 21,137명 중 5%가 이동한다고 가정하면 약 1,057명입니다. 레슨 완료 0회 전체 33,556명에서 콘텐츠 경험률은 약 **3.15%p** 높아집니다. 원본의 약37.01%에서 약40.16%가 되는 가정이며, +5%p와 같지 않습니다.

이 이동률 가정은 A/B 실험의 +3%p/+5%p MDE와 별개입니다. 관찰된 세그먼트 차이를 그대로 개입 효과로 간주할 수 없으므로, 시뮬레이션 금액은 실제 매출 성과나 예측 보장으로 표시하지 않습니다.
