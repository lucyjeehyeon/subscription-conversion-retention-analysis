# 개인 기여와 팀 산출물

## 이지현 담당

초기 학습 퍼널, 활성화·레슨 완료 기준, 콘텐츠 개선 후보, 콘텐츠 난이도 이동, 할인과 결제 관계, 행동 세그먼트 분석을 담당했습니다. PPT를 공동 제작하고 다른 팀원 1명과 공동 발표했습니다.

`notebooks/archive/jeehyeon_activation_analysis.ipynb`는 제공받은 팀 통합 노트북의 원본 셀 215–393(0부터 시작)을 추출한 파일입니다. 원본이 해당 구간을 ‘이지현 팀원 개별 분석 원본’으로 표시하고 있습니다.

## 공동 산출물

`notebooks/archive/team_analysis.ipynb`는 원본 560셀에 안내 셀 1개를 추가한 팀 통합 분석 기록입니다. 개인본은 원본 179셀에 안내 셀 1개를 추가했습니다. 본문과 개인 부록을 함께 보존하며, 개인이 전체 코드를 단독 작성했다는 의미가 아닙니다.

| 원본 구간 (0-based) | 원본에 적힌 구분 |
|---|---|
| 0–118 | 팀 통합 본문 |
| 119–214 | Appendix A · 이서희 |
| 215–393 | Appendix B · 이지현 |
| 394–431 | Appendix C · 장준영 |
| 432–559 | Appendix D · 김은기 |

공용 SQL은 팀 공유 폴더에서 제공받았습니다. Drive 소유자 정보만으로 각 SQL의 작성자를 확정하지 않았습니다. 첫 결제 이후 갱신 분석과 실험·매출 시뮬레이션은 팀 전체 산출물로 소개합니다.
