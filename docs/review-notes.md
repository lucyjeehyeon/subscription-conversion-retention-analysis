# 정정 이력과 검증 범위

2026-10-22에 포트폴리오 소개, 최종 팀 노트북, 33쪽 발표 PDF, 공용 SQL 및 데이터 마트를 대조했습니다. 원시 월별 로그 전체에서 마트를 새로 생성하지는 않았습니다.

## 첫 결제: 확인한 항목

- 최종 팀 노트북 셀 49(0-based)와 PDF 11–12쪽은 4개 세그먼트입니다. 참고용 솔메 노트북의 9개 분류와 구분합니다.
- PDF 8–9쪽과 최종 노트북은 레슨 7회 이상을 후보 기준으로 삼습니다. 참고본의 6회 운영 목표를 최종본에 덮어쓰지 않았습니다.
- 4개 그룹의 유저 수·결제자 수·결제율은 원본 마트에서 재집계했습니다. 결과는 `results/key_metrics.json`에 기록합니다.
- ‘결제 전 7일’은 ‘가입 후 7일 범위 중 첫 결제 이전’으로 풀어 썼습니다.

## 공개본에 반영한 정정

|---|---|---|
| PDF 4쪽 | 평균 첫 결제금액 감소, 평균 할인금액 증가 | 평균 첫 결제금액 30,348→34,958원으로 증가, 평균 할인금액 5,125→1,074원으로 감소하도록 설명 정정 |

공개 발표 자료는 위 정정을 반영해 다시 구성한 [13쪽 PDF](../reports/presentation.pdf)입니다. 원본 33쪽 발표 자료는 사용자 로컬에 보존하고 이 저장소에는 포함하지 않았습니다. 과거 탐색 코드의 수치와 현재 공개 수치가 혼동되지 않도록 원본 분석 흐름은 `notebooks/archive/`, 공용 SQL은 `sql/archive/`에 분리했습니다.

## 갱신 수치가 달라지는 이유와 채택 기준

본문·요약 노트북·공개 발표 자료는 마지막 행의 **무료체험 폐지 후 + 60일 관찰가능** 조건을 사용합니다. 다른 행은 원본의 차이를 추적하기 위한 참고 값입니다.

| 조건 | 저활동 | 활동 | 고활동 |
|---|---:|---:|---:|
| 전체기간 · 관찰가능 필터 없음 (통합본 부록 재현) | 802/1,732 = 46.30% | 1,071/1,883 = 56.88% | 1,003/1,586 = 63.24% |
| 전체기간 · 60일 관찰가능만 | 732/1,558 = 46.98% | 973/1,690 = 57.57% | 906/1,408 = 64.35% |
| 폐지후 · 관찰가능 필터 없음 | 510/1,079 = 47.27% | 835/1,427 = 58.51% | 856/1,362 = 62.85% |
| 폐지후 · 60일 관찰가능만 (통합본 본문 방식) | 440/905 = 48.62% | 737/1,234 = 59.72% | 759/1,184 = 64.10% |

PDF 16쪽의 저활동 676/1,408 = 48.0%는 위 통합본 조건으로 재현되지 않았습니다. 다른 두 그룹이 일치한다는 이유로 표 전체가 같은 모집단이라고 판단하지 않았습니다.
또한 활동일수 30일 초과가 54명 존재합니다. 원본 부록에는 달력 기준 집계에 대한 메모가 있으나, 갱신 마트 생성 쿼리가 확인되지 않아 정확한 경계는 확정하지 않았습니다.

## 추가로 확인할 사항

- 콘텐츠 경험의 조회·시작 변수도 첫 결제 이전으로 통일할 경우 세그먼트 결과가 달라지는지.
- 이벤트 단위 레슨 완료와 고유 레슨 완료를 구분하고 중복 이벤트가 있는지.
- 공용 SQL 생성 순서·중복 적재와 콘텐츠 비율의 분모. `sql/README.md` 참고.
- 발표 PDF의 ‘통계적으로 유의’는 검정 대상·가설·다중비교 처리와 함께 설명할 것. 관찰 차이가 유의하더라도 인과 효과를 의미하지 않음.

## 검증 범위

- 제공된 두 사용자 마트에서 핵심 결제·갱신 집계를 재현하고 공개 JSON과 대조했습니다.
- 공개 요약 노트북은 저장소 루트 및 노트북 폴더에서 실행해 집계 출력이 생성되는 것을 확인했습니다.
- 원본 노트북은 출력과 개인 경로를 정리했으며, 원시 데이터 전체와 기존 실행 환경이 없어 전체 분석을 재실행한 것은 아닙니다.
- 수정 SQL은 분자·분모의 대상이 같도록 작성했으나, 원본 데이터베이스에서 실행 검증하지 않았습니다.
