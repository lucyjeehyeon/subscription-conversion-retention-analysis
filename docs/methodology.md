# 지표 정의

## 첫 결제와 행동의 관찰창

공용 SQL [sql16.sql](../sql/archive/sql16.sql)에서 `*_prepay_7d`는 **가입 시점부터 7일 미만의 범위 중 첫 결제보다 앞선 행동**입니다. 결제 직전으로 거슬러 올라가는 7일이 아닙니다.

| 변수 | 정의·주의점 |
|---|---|
| `paid_30d` | 가입 후 30일 범위에서 최초 결제 이벤트가 있으면 1. SQL의 가입 코호트와 결제 정의를 따름 |
| `lesson_complete_prepay_7d` | 가입 후 7일 미만이면서 첫 결제 이전에 기록된 `complete_lesson` 이벤트 건수. 고유 레슨 수와 구분 |
| `unique_content_prepay_7d` | 같은 시간 범위에서 관찰한 고유 콘텐츠 ID 수 |
| `content_view_7d` / `content_start_7d` | 가입 후 7일 전체의 조회·시작 건수. 첫 결제 이후 행동을 제외하는 조건은 없음 |
| 콘텐츠 경험 있음 | 고유 콘텐츠(결제 전) > 0 또는 가입 후 7일 조회 > 0 또는 가입 후 7일 시작 > 0 |
| 무행동형 | 레슨 완료 0회이며 위 콘텐츠 경험 조건이 거짓. 후기·질문 클릭까지 모두 없다는 뜻은 아님 |

최종 발표용 분류는 레슨 완료 7회 이상 → 1–6회 → 콘텐츠 경험 → 무행동 순서로 4개 그룹을 나눕니다. ‘강한 학습형’과 ‘핵심 학습형’은 원본에서 혼용되어, README에서는 최종 코드 기준 ‘강한 학습형’으로 통일했습니다.

일반 7일 변수와 결제 전 변수를 함께 쓴 결과는 순수한 결제 이전 행동 기반 예측으로 해석하지 않습니다. 결제 시점에 따라 행동을 누적할 수 있는 길이도 달라집니다. 효과 검증에는 동일한 관찰창과 실험 설계가 필요합니다.

## 갱신

공개본은 `is_post_removed = 1`이며 `can_observe_60d = 1`인 **무료체험 폐지 후 가입자 3,323명**을 대상으로 `renewed_60d`의 비율을 집계합니다. 활동일수 구간은 0–4일, 5–13일, 14일 이상이며, 갱신율은 각각 440/905 = 48.62%, 737/1,234 = 59.72%, 759/1,184 = 64.10%입니다.
현재 마트의 `active_learning_days_postpay_30d`에는 최대 32일이 있어, 열 이름만으로 정확한 30일 구간이라고 간주하지 않습니다.

`scripts/reproduce_key_metrics.py`는 전체기간/폐지후, 관찰가능 필터 적용/미적용의 네 조건을 별도로 기록합니다. 공개본은 이 중 폐지후·관찰가능 조건을 일관되게 채택하고, 나머지 조건은 [정정 이력](review-notes.md)에 비교 자료로 남깁니다. 갱신 마트 생성 쿼리는 확보하지 못했으므로 활동일수의 정확한 시간 경계와 플랜별 결제 주기는 추가 확인 대상입니다.
