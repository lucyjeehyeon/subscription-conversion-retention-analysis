# 기존 탐색 기록

이 폴더는 팀 제출 노트북에서 만든 공개용 복사본을 보관합니다. 다운로드한 사용자 원본은 이동하거나 수정하지 않았습니다.

| 파일 | 보존 범위 |
|---|---|
| `jeehyeon_activation_analysis.ipynb` | 원본의 Appendix B · 이지현 개인 분석 구간(원본 셀 215–393) |
| `team_analysis.ipynb` | 팀 통합 본문과 팀원 부록 전체(원본 셀 0–559) |

각 파일에는 안내 셀 1개가 추가되어 있으며, 기존 셀 번호는 `source_cell_index`에 보존했습니다. 팀 통합본을 개인 단독 작성 코드로 표시하지 않습니다.

## 읽는 순서

현재 확인된 결과는 [00_key_results.ipynb](../00_key_results.ipynb)와 [README](../../README.md)에서 확인하세요. 기존 탐색 기록에는 변경 전 표현·잠정 결론·여러 집계 기준·가설 탐색 시도가 남아 있습니다. 기존 표현을 모두 최신 결론으로 보지 않으며, 차이는 [검토 기록](../../docs/review-notes.md)에 설명했습니다.

## 실행 범위

- 보관본은 결과를 다시 산출하는 독립 실행 패키지가 아닙니다. 위에서 아래로 전체 실행을 검증하지 않았습니다.
- 첫 결제·콘텐츠·갱신 마트 외에도 개인 분석에 필요한 월별 이벤트 로그, 콘텐츠 메타데이터 등이 필요합니다.
- 원본 부록의 반복 실행·중간 변수 의존성을 보존했습니다. 보관 위치를 옮겼으므로 상대 데이터 경로는 실행 시 작업 폴더와 함께 확인해야 합니다.
- 모든 셀 출력과 실행 번호를 제거했습니다. 계정 연결, 개인 Drive 경로, 실행형 설치 명령은 공개본에 포함하지 않습니다.
- 원시 이벤트를 재생성하지 않고 이미 검증된 집계 표를 읽으려면 `00_key_results.ipynb`를 실행하세요. 마트 재집계는 [실행 안내](../../docs/reproduction.md)를 따릅니다.
